## Reproduktion

```bash
D="$ARK_L1_DEV_DATA"
for f in $(cd "$D" && ls *.jsonl */*.jsonl); do
  for m in strict balanced; do
    mkdir -p "/tmp/tri/ark-$m/$(dirname "$f")"
    .venv/bin/python scripts/l1_presidio/run_ark.py --pii-mode "$m" --input "$D/$f" --output "/tmp/tri/ark-$m/$f"
  done
  mkdir -p "/tmp/tri/ark-bare/$(dirname "$f")"
  .venv/bin/python scripts/l1_presidio/run_ark.py --pii-mode balanced --gates docs/how-to/pii-bare-formats.gates.json \
    --input "$D/$f" --output "/tmp/tri/ark-bare/$f"
  for p in default tuned; do
    mkdir -p "/tmp/tri/presidio-$p/$(dirname "$f")"
    ~/ark-l1/presidio-venv/bin/python scripts/l1_presidio/run_presidio.py --profile "$p" \
      --input "$D/$f" --output "/tmp/tri/presidio-$p/$f"
  done
done
ENGINES="--ark strict=/tmp/tri/ark-strict --ark balanced=/tmp/tri/ark-balanced --ark balanced-bare=/tmp/tri/ark-bare \
  --presidio default=/tmp/tri/presidio-default --presidio tuned=/tmp/tri/presidio-tuned"
for cmd in m1 m2 report; do python3 scripts/l1_presidio/scoreboard.py "$cmd" --gold "$D" $ENGINES; done
python3 scripts/l1_presidio/count_validated.py count
.venv/bin/python scripts/l1_presidio/latency.py run --engines ark-native ark --ark-python .venv/bin/python \
  --installed-ark --output /tmp/tri/latency.json --markdown /tmp/tri/latency.md
```

Die Bucket-Belege kommen aus einem Vergleich der Vorhersagen von `balanced` und `balanced-bare` je Zeile
(Spans, die nur `balanced-bare` meldet) und der exakten FN/FP je ID mit `scoreboard.resolve_label`.
