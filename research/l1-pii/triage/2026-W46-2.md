## Reproduktion

Wie in [W46](2026-W46.md), zusätzlich:

```bash
# Kompatibilitätsprofil (Vergleich, keine Engine des Urteils)
.venv/bin/python scripts/l1_presidio/run_ark.py --pii-mode balanced --gates docs/how-to/pii-presidio-compat.gates.json \
  --input "$D/$f" --output "/tmp/tri/ark-compat/$f"
python3 scripts/l1_presidio/scoreboard.py m1 --gold "$D" --ark balanced=/tmp/tri/ark-balanced \
  --ark balanced-bare=/tmp/tri/ark-compat --presidio default=/tmp/tri/presidio-default --presidio tuned=/tmp/tri/presidio-tuned
# Latenz Head gegen Base im Wechsel (Base als git archive 66fc95d0, eigener CARGO_TARGET_DIR)
for i in 1 2 3 4; do
  (cd /tmp/base && CARGO_TARGET_DIR=/tmp/target-base python3 scripts/l1_presidio/latency.py run --engines ark-native --output /tmp/tri/lat-base-$i.json)
  python3 scripts/l1_presidio/latency.py run --engines ark-native --output /tmp/tri/lat-head-$i.json
done
```

Die Bucket-Belege kommen aus den exakten FN/FP je Zeile und ID (`scoreboard._row_spans`) im Vergleich
von `balanced` und `balanced-bare`.
